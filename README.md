# gip-disco-at-garage
Garage@EEE events and post-event gatherings often lack vibrant lighting systems that match the energetic and collaborative culture of the makerspace. 
The Disco@Garage project aims to address this by developing a fully configurable, event-ready lighting system tailored specifically for Garage. Members will explore addressable LED control, audio-reactive processing, custom mounting and enclosure design, and reliable power distribution to create a dynamic lighting solution that enhances the overall atmosphere of the space.
